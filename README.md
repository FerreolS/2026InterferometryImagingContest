# 2026 Interferometric Imaging Contest Simulator

InterferometricImagingContest.jl is a Julia package containing the code used for simulating the OBJECT2 of the 2026 Interferometric Imaging Contest. The target is globular cluster. The package bundles the building blocks used in the simulation : stellar spectra synthesis, intrument modeling, complex visibilities, squared visibilities, and closure phases estimation.

## Notebook

 The data simulated for the contest are presented in [notebooks/ContestGlobularClusterData.ipynb](notebooks/ContestGlobularClusterData.ipynb).
